
In 2024 I rebuilt my portfolio as a Rust and WebAssembly app: Leptos for the interface, Axum for the API, and Redis for views and feedback.

I wanted to see how far a Rust-only stack could go on the web. This is what I learned. The site has since moved to Astro and Svelte; this is a record of that earlier build.

## Stack

Leptos compiled the interface to WebAssembly. A small Axum service handled visits and feedback, with Redis for persistence. The API was deliberately narrow: a few endpoints the page actually needed.

## Design

I wanted the site to feel quiet and fast. I looked at [Vercel](https://vercel.com/), [Nio](https://www.nio.com/), [Apple](https://www.apple.com/), and [Nothing](https://nothing.tech/) for restraint, and at [Guille Moreira](https://twitter.com/gzmoreira/) as a reminder of what Latin American developers can build.

The first version shipped with some sections unfinished. I left them visible rather than hiding them. A portfolio should show the work in progress, not just the polished parts.

## Features

### SSR and hydration
- Server-side rendering for the first paint.
- Client-side hydration for the interactive parts.
- A small JavaScript payload.

### Feedback
- A short feedback form on each post.
- Email notifications through Redis and SMTP.
- No account required.

### Analytics
- Per-post view counts.
- Visitor analytics in Redis.
- A dashboard for the numbers I actually used.

## Monitoring

I used [Grafana](https://grafana.com/) and [InfluxDB](https://www.influxdata.com/) for monitoring. InfluxDB stores the time series; Grafana reads it. I wired InfluxDB alerts to a Telegram bot so I would hear about incidents.

![Grafana Dashboard](https://s3.berli.app/portfolio/v1/blog/portfolio-wasm/grafana-1280.webp)

## Deployment

I ran the portfolio on a small home server: Fedora Server 40, Caddy for HTTPS, Cockpit and SSH for administration, Grafana and InfluxDB for monitoring. The current site runs on Proxmox with Caddy and S3 media; the table below describes the 2024 setup.

| Component | Name |
|-----------|------|
| **OS** | Fedora Server 40 |
| **HTTPS Server** | Caddy |
| **Domain** | everdev.it |
| **Administration** | Cockpit and SSH |
| **Monitoring** | Grafana with InfluxDB |
| **Alerts** | InfluxDB with Telegram |
